# Media Control

Lets you control your PC on your phone, for when you want to do a nice movie evening but don't want to spend extra money to get a weird PC remote.

<img src="https://github.com/user-attachments/assets/69a2b5dd-82ca-4c28-ad1c-e386ad07a081" alt="Description" width="450ch" height=auto>

The encryption is very sophisticated (not) but its enough for the local network imo

## Installtion

Due to advances in making everything simple as hell tech, you can just write `dotnet run` in the Server folder and it runs. The default password is pass, change the PASSWORD env var to something else for more security.

If you have too much RAM you can also use the electron server wrapper, it does the same but looks fancier and hides in a tray icon.
